# `@deepseek-ai/dsh-tool-vps-readonly`

This managed-profile tool package exposes seven bounded read-only operations under `/srv/ai-hub`. Each handler validates structured arguments locally and the remote Python helper repeats root and symlink checks before reading. SSH uses the fixed `private@167.233.253.110` destination and a fixed Python command; request data travels as JSON on stdin.

The package grants no write, shell, deployment, Git mutation, controller mutation, or lifecycle capability. Git operations use fixed read-only `status`, `log`, `branch --show-current`, and `rev-parse --verify HEAD` argv with optional locks and filesystem monitoring disabled. `.git` symlinks, worktree `.git` files, config includes, and object alternates are rejected. `vps_find` treats `name` as a literal filename substring and does not follow symlink directories. `vps_search_read` combines a literal exact/contains filename search with one bounded read. It selects only readable regular non-symlink files, revalidates the selected path remotely, and returns an ordered candidate list without reading when `result_index` is `auto` and the result is ambiguous. Use `auto` only for unique results or a decimal zero-based index from 0 to 99; arbitrary glob and regex matching are unavailable. `vps_repo_summary` composes a top-level listing, bounded tracked-file status, branch, HEAD, recent log, and names of a fixed set of common metadata files. It returns no file contents, omits untracked files from the dirty calculation, and reports metadata names only.

Output limits are 200 directory entries, 100 search results, 300 text lines (starting no later than line 10,000), 32 KiB of file or Git text, 64 KiB per serialized result, and 50 commits for Git history. Repo summaries return at most 50 top-level entries, 20 commits, and 16 KiB of status text. Directory enumeration stops after 10 seconds; search stops after 20 seconds or 100,000 entries. Binary files are rejected. The DSH schema presents numeric bounds as decimal strings, and the handler converts only digit-only values before enforcing these limits. Permission-denied paths are skipped or reported as read errors; they do not cause a broader identity or access path to be used.

## Known Limitations and Deferred Work

The SSH account can read only a subset of `/srv/ai-hub`; inaccessible directories remain inaccessible. The tools do not expose authoritative Controller state. Use the existing `ai-hub-status` read-only projections for their specific persisted-state operations.
